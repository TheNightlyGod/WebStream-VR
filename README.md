# WebStream-VR

Трансляция того, что видно в Meta Quest, в браузер по локальной сети. Приложение
ставится на шлем, запускает системный кастинг Meta, сам принимает его поток и
раздаёт страницу просмотра. Открыть её можно с телефона, ПК или телевизора в той
же Wi-Fi-сети. ПК, adb и root для работы не нужны.

## Что умеет

- Видео H.264 до 2560×1440 и около 60 к/с, звук приложений 48 кГц стерео.
- Задержка в браузере 0,1–0,3 с (MSE с удержанием у живого края).
- Несколько зрителей одновременно. Отстающий зритель сам догоняет с ближайшего ключевого кадра.
- Настройки в приложении на шлеме: разрешение, битрейт, глаз, расширение обзора,
  стабилизация, звук, порт. Меняются на лету без переподключения.
- Само восстанавливается, если системный сервис кастинга упал или переподключился.

## Требования

- Quest 2 / 3 / 3S / Pro на Horizon OS с Android 14 и сервисом
  `com.oculus.magicislandcastingservice`. Он есть в прошивке, его же использует
  Meta Quest Developer Hub.
- Режим разработчика, чтобы поставить APK.
- Браузер с Media Source Extensions: Chrome, Edge, Firefox, Safari 17+ (iOS 17.1+).

## Сборка и установка

Нужен Android SDK (platform 37) и JDK. Gradle сам скачает JDK 25 через foojay.

```bash
./gradlew assembleDebug
```

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

После этого приложение лежит в шлеме в «Библиотеке → Неизвестные источники».

## Как пользоваться

1. Открыть WebStream-VR в шлеме и нажать «Начать трансляцию».
2. Открыть показанный адрес (например, `http://192.168.1.5:8080`) на любом
   устройстве в той же сети.
3. Звук в браузере включается кнопкой «Включить звук»: без нажатия браузеры
   не дают странице играть звук. F — полный экран, M — звук.

Приложение можно свернуть или запустить игру: трансляция работает в фоне.
Остановить её можно в приложении или из уведомления.

Управление через adb (удобно для автоматизации):

```bash
adb shell am start -n xyz.lukioff.webstreamvr/.MainActivity -a xyz.lukioff.webstreamvr.START
```

```bash
adb shell am start -n xyz.lukioff.webstreamvr/.MainActivity -a xyz.lukioff.webstreamvr.STOP
```

`GET /api/status` отдаёт состояние в JSON.

## Ограничения

- **Страница без пароля и без шифрования**: смотреть может любой в той же сети.
  Не запускайте трансляцию в общественном Wi-Fi.
- Одновременно работает только одна трансляция кастинг-сервиса. Если идёт каст
  из MQDH или на телефон, приложение не подключится. Поможет перезагрузка шлема.
- Пока идёт трансляция, в шлеме горит индикатор записи, а экран не гаснет, даже
  если шлем снять (так делает сам кастинг-сервис).
- Частота кадров фактически около 60 к/с: шлем игнорирует настройку `fps`.
- Работает, пока Meta оставляет ресивер сервиса открытым. Подробности в
  [docs/PROTOCOL.md](docs/PROTOCOL.md#управление-сервисом-интенты).

## Как это устроено

```
app/src/main/java/xyz/lukioff/webstreamvr/
  cast/CastingServiceControl.kt   интенты START_SERVICE / CONNECT
  cast/HeadsetLink.kt             loopback-сервер, два сокета, сессия, переподключение
  cast/Xrsp.kt                    пакеты XRSP и сборка датаграмм MGIK
  cast/MagicMessages.kt           сообщения MagicIsland
  web/WebServer.kt                HTTP + WebSocket без зависимостей
  web/ViewerHub.kt                раздача кадров зрителям с контролем отставания
  StreamService.kt                foreground-сервис, связывает всё вместе
  ui/MainScreen.kt                экран настроек (Compose)
app/src/main/assets/web/          страница просмотра: fMP4-мультиплексор, MSE, Web Audio
```

Протокол и все находки описаны в [docs/PROTOCOL.md](docs/PROTOCOL.md).

## Разработка страницы без шлема

Записать несколько секунд потока с работающего приложения:

```bash
python3 tools/capture_ws.py http://192.168.1.5:8080 10 capture.h264
```

Проиграть запись тем же протоколом и открыть `http://127.0.0.1:18090`. Файлы из
`app/src/main/assets/web` подхватываются без пересборки APK.

```bash
python3 tools/replay_server.py capture.h264 --tone
```

Тесты протокола:

```bash
./gradlew testDebugUnitTest
```

В консоли браузера доступен `window.webstream` (конвейер видео, аудио, состояние).
