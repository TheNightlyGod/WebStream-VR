# WebStream-VR

Трансляция того, что видно в Meta Quest, в браузер по локальной сети. Приложение
ставится на шлем, запускает системный кастинг Meta, сам принимает его поток и
раздаёт страницу просмотра. Открыть её можно с телефона, ПК или телевизора в той
же Wi-Fi-сети. ПК, adb и root для обычной работы не нужны.

## Что умеет

- **Защита PIN-кодом**: при каждом запуске трансляции генерируется 6-значный код подключения, исключающий посторонний просмотр в сети. Можно передавать код прямо в URL (`?code=123456`).
- **Автоматическая установка кастинг-сервиса**: если на шлеме отсутствует или устарел необходимый системный сервис `com.oculus.magicislandcastingservice`, его можно установить или обновить в 1 клик прямо из приложения.
- **Высокое качество**: видео H.264 до 2560×1440 и до 60 к/с, звук приложений 48 кГц стерео.
- **Минимальная задержка**: 0,1–0,3 с в браузере (MSE с удержанием у живого края).
- **Многопользовательский режим**: несколько зрителей одновременно, каждый отстающий зритель автоматически догоняет эфир с ближайшего ключевого кадра.
- **Гибкие настройки**: соотношение сторон (16:9, 4:3, 1:1, 9:16, «Как в шлеме»), качество (720p/1080p/1440p), битрейт (Auto, 4–20 Мбит/с), частота кадров (30/60 к/с), выбор глаза, расширение обзора (FOV), стабилизация, звук, HTTP-порт.
- **Фоновая работа и устойчивость**: фоновый сервис с удержанием Wi-Fi и Power lock, автоматическое восстановление при сбоях системного сервиса.

## Требования

- Quest 2 / 3 / 3S / Pro на Horizon OS (Android 14+).
- Сервис `com.oculus.magicislandcastingservice` (встроен в приложение и при необходимости устанавливается из него).
- Режим разработчика на шлеме для установки APK приложения.
- Браузер с поддержкой Media Source Extensions (MSE): Chrome, Edge, Firefox, Safari 17+ (iOS 17.1+).

## Сборка и установка

Нужен Android SDK (platform 37) и JDK. Gradle сам скачает JDK через foojay.

```bash
./gradlew assembleDebug
```

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

После установки приложение находится в шлеме в разделе «Библиотека → Неизвестные источники».

## Как пользоваться

1. Открыть WebStream-VR в шлеме. Если сервис кастинга не установлен или устарел, нажать «Установить сервис».
2. Нажать «Начать трансляцию».
3. На экране шлема отобразятся адрес (например, `http://192.168.1.5:8080`) и **6-значный код подключения** (например, `123456`).
4. Открыть показанный адрес на любом устройстве в той же Wi-Fi-сети и ввести код (или сразу перейти по ссылке вида `http://192.168.1.5:8080?code=123456`).
5. Нажать «Включить звук» на странице для воспроизведения аудио. Клавиша **F** — полный экран, **M** — выключение звука.

Приложение можно свернуть или запустить игру: трансляция продолжит работать в фоне. Остановить её можно в приложении или из системного уведомления.

Управление через ADB:

```bash
adb shell am start -n xyz.lukioff.webstreamvr/.MainActivity -a xyz.lukioff.webstreamvr.START
```

```bash
adb shell am start -n xyz.lukioff.webstreamvr/.MainActivity -a xyz.lukioff.webstreamvr.STOP
```

Эндпоинт статуса (требует код): `GET /api/status?code=123456`

## Ограничения

- Поток передаётся по HTTP/WebSocket в локальной сети. Защита PIN-кодом ограничивает доступ на уровне веб-интерфейса и WebSocket.
- Одновременно работает только одна трансляция кастинг-сервиса. Если идёт каст через MQDH или на телефон, перед стартом WebStream-VR его необходимо остановить.
- Во время трансляции в шлеме отображается системный индикатор записи.

## Архитектура проекта

```
app/src/main/java/xyz/lukioff/webstreamvr/
  cast/
    CastingServiceControl.kt   Интенты START_SERVICE / CONNECT для сервиса кастинга
    CastingServiceInstaller.kt Проверка версии и установка APK сервиса из ресурсов
    HeadsetLink.kt             Loopback TCP-сервер, сокеты, управление сессией и переподключение
    MagicMessages.kt           Формат сообщений протокола MagicIsland
    Xrsp.kt                    Разбор пакетов XRSP и сборка датаграмм MGIK
  web/
    H264.kt                    Сканер Annex-B NAL-юнитов (SPS, PPS, IDR, Slice)
    WebServer.kt               HTTP-сервер, проверка PIN-кода, обработка WebSocket /ws
    WebSocket.kt               Реализация RFC 6455 (хэндшейк, фреймы)
    ViewerHub.kt               Раздача кадров зрителям с синхронизацией ключевых кадров
  ui/
    MainScreen.kt              Экран управления и настроек (Jetpack Compose)
    theme/                     Цветовая схема и шрифты Material 3
  StreamService.kt             Foreground-сервис, генерация PIN-кода, блокировки Wi-Fi/Power
  StreamSettings.kt            Хранение настроек, расчёт параметров кадра
  MainActivity.kt              Запуск UI, обработка сторонних интентов и прав
app/src/main/assets/
  com.oculus.magicislandcastingservice.release.apk  Встроенный APK кастинг-сервиса
  web/                         Страница просмотра (index.html, player.js, mp4.js, style.css)
```
